# my-first-project

A small practice project created while learning to work with Claude Code (part of the `curso-claude` course).

## Contents

| File        | Description                                                        |
|-------------|--------------------------------------------------------------------|
| `hello.txt` | A simple "hello" text file.                                         |
| `poem.txt`  | *The Sea* — a four-stanza rhyming poem about the ocean.            |

## Purpose

This project is a sandbox for experimenting with Claude Code features such as
creating, reading, and editing files from the terminal. There is no code to
build or run.
