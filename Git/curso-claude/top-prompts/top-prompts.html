Livro de receitas

5 prompts que me ensinaram a usar o Claude Code

Texto exato, o que aconteceu, a lição. Uma tela por prompt. Use ← → ou os botões.

  1. O primeiro arquivo
  2. O arquivo vazio
  3. Dois pedidos num só

01 · O primeiro arquivo

Comece pequeno para ver como funciona

make a file called hello.txt that says hello
O que o Claude fez

Criou hello.txt com a palavra “hello”. Depois rodei ls e cat hello.txt para conferir.

O que aprendi

Nome do arquivo + conteúdo = pedido completo. E sempre verifique o resultado você mesmo.

02 · O arquivo vazio

Quando der errado, diga o que esperava

write a poem about the sea in a file called poem.txt
the file was created but it's empty - I expected the poem
O que o Claude fez

Na primeira vez o arquivo saiu vazio. Com a correção, escreveu “The Sea”, quatro estrofes rimadas.

O que aprendi

Uma boa correção descreve o que aconteceu e o que eu esperava. Não precisa recomeçar do zero.

03 · Dois pedidos num só

Agrupe tarefas relacionadas

add a README.md describing this project, and a .gitignore
O que o Claude fez

Leu a pasta, escreveu um README com tabela dos arquivos e criou um .gitignore, tudo de uma vez.

O que aprendi

“Descreva este projeto” funciona porque o Claude lê o que já existe. Não preciso explicar o que ele pode ver.

04 · O prompt cortado

Faltou informação? Ele preenche com marcadores

make a file called index.html - a simple one-page website about me, with my name as a
O que o Claude fez

Mandei a frase pela metade. Mesmo assim saiu um site com tema claro/escuro e “Your Name” no lugar do meu nome.

O que aprendi

Revise antes de enviar. O que eu não disser, o Claude não tem como adivinhar: vira texto provisório.

05 · O prompt com formato

Defina a estrutura de cada item

escreva um arquivo chamado cheatsheet.md com os 10 comandos de shell que um iniciante deveria aprender primeiro. para cada um, dê o comando, uma linha sobre o que ele faz e um exemplo real de quando eu usaria.
O que o Claude fez

Dez comandos, cada um com “o que faz”, “quando usar” e exemplo. Ainda incluiu avisos sobre rm e atalhos bônus.

O que aprendi

Quantidade + público + formato de cada item = o melhor resultado até agora. Escrever em português também funciona.
